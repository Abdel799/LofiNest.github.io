# Welcome to Lofi Nest
--------------------------
Lofi Nest is a study platform designed to help students be productive with every-day tasks.

# Functionality
--------------------------
This platform combines:

1. Music streaming: Users have a choice of different uninterrupted streaming channels that plays throughout the application such as...
   - Study beats 📖
   - Chill 🌙
   - Hip-Hop 📚
   - Jazz 🎵
   - Synth wave 🌆
   - Calm 🌊
     
2. AI assistance: Built using Groq API, this AI assistant has multiple saved chat histories that users can revisit anytime. Users can create
   as many chats as they'd like and inquiry about any topic.
   
4. Note-taking: Users can create, edit, and delete as many documents as they'd like. Each document has font formatting options such as:
   - Font style: Arial, Times New Roman, Courier New, Georgia
   - Bold
   - Underline
   - Italicize
   - Margin aligning
   - Font size
  
5. Calendar functionality: Users can add, edit, and delete events to any calendar day, helping users keep track of assignments, deadlines, and day to day activities.

6. Pomodoro study timer: A study timer designed to help users focus on their required tasks.
